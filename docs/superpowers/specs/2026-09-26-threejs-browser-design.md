# 《加工所：制高點》Three.js 瀏覽器版

2026-09-26 使用者核准並要求直接實作瀏覽器版本。

## 核准範圍

- TypeScript、Vite、Three.js；電腦 Chrome／Edge、鍵盤滑鼠、固定觀測台，不提供自由走動、飛行或手機觸控。
- 六張地圖、18 個驅逐任務、通關混合挑戰、自由模式、五種彈藥、雙貨幣、裝備升級、頭飾收藏、協力者。
- 場景、槍械、物件及油庫里由 Three.js 建模；共用幾何、材質，重複場景物件採 InstancedMesh。表情以程式繪圖生成。
- 通常種：靈夢（黑髮、紅白蝴蝶結）、魔理沙（金髮側辮、黑尖帽）、愛麗絲（金色短髮、紅髮箍）、帕秋莉（紫長髮、月亮軟帽）、橙（棕短髮、貓耳綠帽）、妖夢（銀白短髮、黑蝴蝶結）。種類決定外觀，角色資料決定速度及行為。
- 協力者使用相同模型工廠，正面綠色圓徽章；邏輯陣營與模型外觀分開。
- 六區為公園、都市後巷、住宅庭院、商店街、工廠、農村梯田，各有固定觀測點、地面路線與遮蔽射擊窗口。
- 固定時間步進、原版風偏及重力近似；Raycaster 選擇最近命中，遮蔽物擋彈。自由模式累計出生不設上限，當前存活及芽殖預約有容量限制。
- 版本化 localStorage，保留備份及損毀原文；失敗提示、交易回復、不重複結算。新進度起步。
- 滑鼠轉向、左右鍵射擊／瞄準鏡、滾輪倍率、R 換彈、1–5 彈種、Esc 暫停；失焦、解鎖及分頁切換必須暫停且不自行恢復。
- 繁體中文辦公桌、任務板、地圖冊、軍械櫃、社區聯絡簿；新增模型展示供檢視六種及協力者徽章。

## 開發及驗收

入口為根目錄 `web/`。資料、規則、顯示、輸入、介面與存檔分離。順序為模型及公園基礎、完整單區流程、六區完整內容、瀏覽器驗收交付。

驗收含所有任務資料及規則、每區驅逐與自由模式、六種與五彈種、貨幣／保存／解鎖／結算、分頁／縮放／滑鼠及儲存異常、Chrome／Edge 1080p、實際 30 分鐘自由模式和 GPU 資源有界。交付原始碼、繁中 PowerShell 啟動腳本、操作說明、測試紀錄及 dist 靜態產物。公開部署、帳號、雲端存檔不在本次範圍。

本次實作採 60 Hz 固定規則步進。驗收方法、證據與實測限制以 `web/VALIDATION.md` 為準。
