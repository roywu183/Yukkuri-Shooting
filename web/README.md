# 《加工所：制高點》Three.js 版

固定制高點的第一人稱狙擊遊戲，支援電腦 Chrome、Edge。六種通常種為靈夢、魔理沙、愛麗絲、帕秋莉、橙、妖夢；均有獨立的程式建模髮型與頭飾。

## 遊玩

執行 `啟動遊戲.ps1`。腳本會安裝缺少的鎖定套件、在背景啟動本機伺服器並開啟 `http://127.0.0.1:4173/`。可加 `-NoOpen` 只啟動伺服器。

| 操作 | 功能 |
|---|---|
| 滑鼠 | 轉動視角（固定觀測台，無角色移動） |
| 左鍵 | 射擊 |
| 右鍵 | 切換瞄準鏡 |
| 滾輪 | 往上放大、往下縮小（三段倍率） |
| R | 換彈 |
| 1–5 | 普通／辣椒／咖啡／彈珠汽水／芽殖彈 |
| E | 自由模式回收完整頭飾 |
| Esc | 暫停並釋放滑鼠 |

切換分頁、視窗失焦、滑鼠控制解除均會暫停；必須點「繼續勤務」恢復。第一次出勤需透過按鈕授予滑鼠控制。

## 遊戲內容

- 野生個體在安全地面隨機出生；長期種類比例為靈夢 35%、魔理沙 35%、橙 10%、愛麗絲 10%、帕秋莉 5%、妖夢 5%，包含家庭成員。一般體型為 0.7–1.3 倍，每次出勤重新隨機。
- 有至少四個出生名額時，每次生成事件有 30% 機率出現一家：大靈夢、大魔理沙、小靈夢、小魔理沙。父母體型 1.05–1.25 倍、幼體 0.44–0.58 倍，維持隊形一起移動；一隻受傷後其餘驚慌四散。協力者誘餌與干擾效果以整家同步處理。地形過度擁擠、無法安排安全隊形時，四隻改為分散出生。
- 新增 91 句原文台詞，以角色上方文字氣泡隨機呈現；依種類、大小及閒晃／目擊死亡／臨終情境選詞。共通與專屬台詞混合抽取，名字自動代入。同時最多五個氣泡，臨終與驚慌優先，暫停時隱藏；此項為文字台詞，沒有新增語音配音。
- 移動每 2–6 秒或抵達目標後重新選擇方向，偶爾短暫停頓；個體速度為舊基礎速度的 2.2–3.4 倍。整段移動避開設施與邊界，農村依梯田地面高度移動。
- 成年個體被芽殖彈命中時，莖從額頭朝前彎伸，1–3 隻幼體沿莖下方垂掛，約 5 秒後落地至附近安全位置，體型為 0.42–0.62 倍。同一成年個體生產後可再次芽殖。小油庫里被命中時會原地抖動並說出固定台詞「阿阿阿不要吸走生命的餡子阿阿!!」，同樣長出枝條，但不會有幼體落地出生；母體與枝條上的油庫里一起乾扁死亡，帶枝條的屍體留在現場。
- 公園、都市、住宅區、商店街、工廠、農村各三個任務；完成六區後開放聯合挑戰。
- 全數處置並達成特殊條件才解鎖後續任務；可提早回報領取依完成率計算的點數。
- 每區首關完成後開放該區自由模式，無時間與累計出生數限制。
- 普通彈處置；辣椒彈命中後先變紅膨脹，約 0.65 秒後爆炸並破壞頭飾，飛散肉片接觸其他油庫里會觸發連鎖爆炸；咖啡彈範圍中毒，約 2 秒後毒死；汽水彈睡眠；芽殖彈使成年個體僵直並預約 1–3 隻幼體；命中小油庫里則於生長結束後與枝條上的油庫里一同死亡。
- 自由模式每次處置取得 5 社區點數；完整收藏套裝提升為四捨五入後的 1.5 倍。普通彈可免費無限裝填。四種特殊彈各自計數，每場每種攜帶 3 發；購買擴充彈匣後提升至 5 發，不能於場內補充。
- 手動回收保留頭飾收藏；回收專長協力者收集的頭飾在結算時折算點數。
- 每區三名協力者，最多兩名出勤，可招募、升級、選擇。綠色徽章是協力者識別，邏輯使用獨立 helper 欄位。
- 自由模式普通補生維持基本族群 12 隻，芽殖可突破此數量且無總數上限；地面掉落物最多 24 件、120 秒消退。回收收藏用固定種類計數表保存。

一般彈與咖啡彈死亡後會變成暗褐色，經約一秒從圓饅頭逐漸下沉、變扁橢圓並向外攤平，留下癱軟屍體，毒死保留中毒臉，屍體留到離開本場。同圖可活動夥伴目擊攻擊後會露出驚慌臉，以 2.5 倍速度朝遠處逃散約 6–8 秒。

## 音效

- 分層合成五種槍聲與槍機聲；換彈依實際進度播放卸彈、裝填、上膛三段聲音，另有空膛、切彈、開鏡與倍率調整聲。
- 命中、設施彈跳、誤傷警告、辣椒燃燒與連鎖爆炸、芽殖生長／出生／落地、睡眠／僵直／恢復、頭飾回收、選單操作及勤務結算均有對應提示。
- 場景搭配低音量風聲、鳥鳴或機械低鳴；角色彈跳聲及現場效果具有距離衰減與左右聲道定位。
- 選單和暫停畫面右下角可調整音量或靜音，設定會保存在此瀏覽器。第一次點擊後啟用音訊；暫停會停止現場聲音，恢復後換彈仍依剩餘遊戲時間繼續。
- 音效在本機由 Web Audio 合成，不需下載音檔。連鎖事件有播放節流與總音量壓縮，聲源用完會釋放。

## 存檔與進度

使用版本化 `localStorage`，鍵值 `highground.web.v1`；備份鍵為 `.backup`，損毀原文另存 `.corrupt.<時間>`。保存失敗不扣交易費用；結算頁可重試，或明確選擇放棄未保存結果。

進度依瀏覽器與網站來源分開：開發用 5173 與遊玩用 4173 的存檔不同。清除網站資料會刪除存檔。此版本不含帳號或雲端同步。

## 開發與驗證

```powershell
npm.cmd ci --cache .npm-cache --no-audit --no-fund
npm.cmd run dev
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

開發網址為 5173。另開終端執行：

```powershell
npm.cmd run test:browser
$env:BROWSER_CHANNEL = 'msedge'
npm.cmd run test:browser
Remove-Item Env:BROWSER_CHANNEL
npm.cmd run test:soak
```

瀏覽器測試使用本機已安裝的 Chrome／Edge、1920×1080 與獨立暫存瀏覽器資料，不接觸玩家存檔。測試 fixture 只存在於 `tools/`。長跑預設 1800 秒，可用 `SOAK_SECONDS` 指定；少於 1800 秒僅能作冒煙測試。

測試輸出及截圖在 `test-results/`，完整驗收摘要見 `VALIDATION.md`。`npm run build` 同時執行 TypeScript 檢查。Windows 沙箱下採 native 設定載入及停用開發依賴預打包，避免 esbuild 探查不可讀上層目錄。

交付時通過的 JSON 與畫面封存在 `validation/`，不會被下一次測試覆寫。`node tools/campaign-journey.mjs` 可另跑全新存檔的 19 關瀏覽器操作；`node tools/package-evidence.mjs` 會在完整長跑與其他報告均通過、來源 SHA-256 相符後更新證據封存。

## 架構與部署

- `src/data`：遊戲內容快照、六種外觀及具型別內容。
- `src/game`：固定時間步進、彈道、狀態機、計分、交易及存檔。
- `src/render`：Three.js 模型、六區場景、射線命中與距離標尺。
- `src/main.ts`、`src/ui`：繁體中文介面、操作協調及 Web Audio 音效。

`dist/` 可直接部署到任意靜態網站伺服器，資源路徑使用相對位置。禁止以 `file://` 直接雙擊 HTML；請透過 HTTP(S) 開啟。`main` 分支推送後，GitHub Actions 會重新建置並將 `web/dist/` 發布至 GitHub Pages。無外部模型、貼圖、字型或 API 依賴；Node.js 僅用於開發、建置與本機伺服器。
