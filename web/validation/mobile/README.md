# 手機支援驗證

`node tools/mobile-browser.mjs` 在 Chrome 使用手機識別字串、觸控事件與手機 viewport 進行流程驗證，報告在 `results.json`。

- 390×844、844×390、320×568、667×375 四種尺寸。
- 主畫面方向選擇、勤務簡報、部署與無滑鼠鎖定的操作。
- 實際 Touch 事件拖曳瞄準、第二指射擊、觸控取消後重新瞄準。
- 換彈、開鏡、倍率、彈種切換、自由巡守回收。
- 暫停時鐘、恢復、轉向暫停、改用目前方向與結果頁。
- 觸控按鈕至少 44px 高、可點擊且位於畫面內，沒有水平溢出。
- 桌面主畫面維持原有操作，不顯示手機選項。
- 手機方向偏好可在重新載入後恢復，六個選單在手機尺寸沒有水平溢出。

另以正式 `dist` 執行直向／橫向的部署、射擊扣彈、開鏡、暫停、恢復與結算保存，結果在 `production.json`。本次 111 項單元測試、TypeScript／Vite 建置、桌面六區戰役／自由巡守回歸及正式版桌面冒煙測試均通過。

這是 Chrome 手機模擬驗證；尚未在實體 Android／iPhone 驗證效能及 Safari 原生方向鎖定。測試刻意拒絕全螢幕，涵蓋無法鎖定方向時的手動轉向流程。
