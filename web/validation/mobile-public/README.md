# 兩個公開網址的驗證

2026-09-28：手機支援分支已合併至 `main`，兩個 GitHub Pages 網址發布相同建置，皆自動判斷裝置。

- `results-original.json`：原遊戲網址的公開驗證。
- `results-mobile.json`：第二個遊戲網址的公開驗證。
- 手機模擬涵蓋 iPhone、Android Chrome 的直向／橫向，以及桌面識別字串搭配一個觸控點。
- 每種手機情境都切換繁體中文、簡體中文與日本語，檢查方向區的標題、兩個按鈕及完整說明。
- 手機能部署、射擊、開鏡、調整倍率、暫停、恢復及結算保存；桌面不顯示手機方向選擇，正常取得滑鼠鎖定。
- 114 項單元測試及 TypeScript／Vite 建置通過。兩個公開網址的遊戲程式 SHA-256 均與本機建置相符。

這些是 Chrome 的裝置模擬驗證，不代表實體手機效能測試。較早的固定手機版驗證屬於過去版本；目前以本目錄的兩份公開網址報告為準。
