# 加工所：制高點

目前開發版本為 **Three.js 電腦瀏覽器版**。全部場景、物件與六種油庫里以程式建立 3D 模型。

執行 `啟動瀏覽器版.ps1`，或在 PowerShell 輸入：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\啟動瀏覽器版.ps1
```

正式本機網址：`http://127.0.0.1:4173/`。首次啟動需要 Node.js 22 以上與網路安裝套件；套件就緒後遊戲可離線使用。

完整操作、測試與部署說明見 [web/README.md](web/README.md)。
